# VS C++ CsvImportExport

Open `CsvImportExport.sln` in Visual Studio 2019 and build `Debug|Win32` or `Release|Win32`. The project emits `CsvImportExportMsvc.plg` directly into `bin\Debug` or `bin\Release`.

The example depends only on `SDK/examples/shared/cpp` and `SDK/include/cpp/TonCutPluginSdk.hpp`. It covers CSV import/export plus single-sheet PLT result export; the wider TonCut surface is documented in `SDK/manuals/plugin-contract-and-abi.md` and `SDK/manuals/support-by-language.md`.
